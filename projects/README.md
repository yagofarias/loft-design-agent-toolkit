# Projetos

Esta pasta contém os projetos criados com o toolkit. Cada projeto tem sua própria subpasta com todos os arquivos gerados pelos agentes.

Esta pasta está no `.gitignore` — os seus projetos nunca são afetados por atualizações do toolkit.

## Estrutura de um projeto

```
projects/
  nome-do-projeto/
    design-doc.md          ← gerado pelo /framing
    design-doc.docx        ← versão para Google Docs (opcional)
    journey-spec.md        ← gerado pelo /journey
    critique-output.md     ← gerado pelo /critique
    tracking-spec.md       ← gerado pelo /handoff
```
